Setup Guide

Connect your camera

Openeye can use any camera that OpenCV can open. This guide covers USB webcams, built-in laptop cameras, and IP/CCTV cameras that stream over RTSP.

1

USB webcam or built-in camera

The fastest way to start monitoring.

Plug it in

Connect your USB webcam to the computer. If you are on a laptop, the built-in FaceTime camera is usually used by default.

Pick the right camera index

OpenCV numbers cameras starting from 0. On most computers:

  • 0 = built-in webcam (MacBook FaceTime camera)
  • 1 = first USB webcam
  • 2 = second USB webcam, and so on

Change the setting

Open the .env file in the project root and set:

# Use 0 for built-in webcam, 1 for your first USB webcam
CAMERA_INDEX=0

Find your camera index

If you are not sure which index is correct, run this quick test:

python3 -c "import cv2
for i in range(4):
    cap = cv2.VideoCapture(i)
    print(i, 'works' if cap.isOpened() else 'no camera')
    cap.release()"

Tip: The index that prints works and shows the camera you want is the one to put in .env.

Restart the app

Save .env, stop the running server, and start it again:

python3 -u app.py
2

CCTV / IP camera with RTSP

Connect network cameras over your local network.

What is RTSP?

RTSP is the standard streaming address most IP cameras use. It looks like a URL: 

rtsp://username:password@camera-ip-address:554/stream-path

Find your camera's RTSP URL

  • Check the camera's manual or the brand's support site.
  • Common brands use paths like /live/ch00_0, /stream1, or /cam/realmonitor?channel=1&subtype=0.
  • You can also search for "your-camera-brand RTSP URL".

Example RTSP URLs

# Hikvision
rtsp://admin:password@192.168.1.100:554/Streaming/Channels/101

# Dahua
rtsp://admin:password@192.168.1.100:554/cam/realmonitor?channel=1&subtype=0

# Tapo / TP-Link
rtsp://admin:password@192.168.1.100:554/stream1

# Generic ONVIF camera
rtsp://admin:password@192.168.1.100:554/live/ch00_0

Code change needed

Openeye is currently set up for USB camera indexes. To use an RTSP URL, you need to change one function in backend/detector.py and one in backend/app.py.

Step A — Add a camera URL setting

Open .env and add a new line:

# RTSP camera URL (leave empty to use USB camera index)
CAMERA_URL=rtsp://admin:password@192.168.1.100:554/stream1

Step B — Read the new setting

Open backend/config.py and add this line near the other camera settings:

CAMERA_URL = os.environ.get("CAMERA_URL", "")

Step C — Use the URL when it is set

In backend/detector.py, find the fetch_frame() function. Change the live-camera part from: 

cap = cv2.VideoCapture(config.CAMERA_INDEX)

to:

cap = cv2.VideoCapture(config.CAMERA_URL or config.CAMERA_INDEX)

In backend/app.py, find the _get_camera() function. Change: 

_camera = cv2.VideoCapture(config.CAMERA_INDEX)

to:

_camera = cv2.VideoCapture(config.CAMERA_URL or config.CAMERA_INDEX)

Restart the app

After saving the files, restart the server:

python3 -u app.py

Note: If the RTSP stream does not appear, make sure the camera and the computer are on the same network and that the username, password, and stream path are correct.

3

Quick checks

If the dashboard feed is blank or shows the wrong camera.

Wrong camera?

Try the next index: 0, 1, 2, 3. Update CAMERA_INDEX in .env and restart.

No camera in Docker?

Docker cannot see your USB webcam unless you pass the device through. Use Demo mode with an uploaded video, or run locally with python3 -u app.py.

Permission blocked?

On macOS, go to System Settings → Privacy & Security → Camera and allow your terminal or Python to use the camera.

RTSP lag?

Use a lower-resolution sub-stream path such as /stream2 or subtype=1 for a smoother feed.
